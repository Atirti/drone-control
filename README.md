# Du-HD4K — управление и видео

Windows-приложение на C# / .NET 10 WPF для дрона с Wi-Fi `Du-HD4K-1072B853`. Интерфейс использует Material Design. Пользователь подтвердил работу видео и прежнего кнопочного управления. Экранные стики и геймпад ещё не проверены в полёте.

## Быстрый запуск

1. Подключите Windows к Wi-Fi дрона.
2. Запустите `dist/DroneControl/DroneControl.exe`.
3. Нажмите **Подключить**. Адрес `192.168.169.1:8800` уже задан; видео появляется автоматически.

Для готовой сборки нужен **.NET 10 Desktop Runtime**. Для запуска из исходников нужен **.NET 10 SDK**:

```powershell
dotnet run --project src/DroneControl -c Release
```

Подключение само по себе не отправляет полётных команд. Первую проверку управления выполняйте со снятыми пропеллерами. Нейтраль осей не гарантирует зависание или посадку; при потере связи доставка команды остановки не гарантируется.

## Управление

Выберите **Экранные стики** или **Геймпад**, дождитесь ответов дрона и включите **Включить управление**. Раскладка обоих источников одинаковая.

- Левый стик: вверх/вниз — газ, влево/вправо — поворот.
- Правый стик: вперёд/назад и движение в стороны, включая диагонали.
- Экранные стики работают мышью или двумя пальцами на сенсорном экране; при отпускании возвращаются в центр.
- Геймпад подключается через библиотеку SDL3-CS. В режиме **Геймпад** движения видны на экране даже без дрона. После включения управления отпустите оба стика на 0,3 секунды.

Потеря фокуса, смена источника или отключение геймпада снимают разрешение управления. После восстановления включите его вручную. На геймпаде: **LB** — скорость 30 → 60 → 100 → 30%, **↑ крестовины** — взлёт, **↓** — посадка, **B** — стоп моторов. Экранные кнопки также доступны.

Слайдер **Скорость** выбирает режим 30/60/100%, начальное значение — 30%. По APK эти режимы задают правому стику диапазоны ±45/±60/±127; газ и поворот остаются ±127 во всех режимах. Это не измеренная скорость в км/ч. **Взлёт** и **Посадка** передают команду в течение секунды. **СТОП МОТОРОВ** доступен при открытом соединении независимо от разрешения управления. **Снимок** сохраняет текущий кадр в PNG.

## Просмотр в VLC

Запустите `Start-VideoBridge.ps1`, затем откройте в VLC через Ctrl+N:

```text
http://127.0.0.1:8088/video.mjpg
```

Также можно открыть `drone-video.m3u`. Остановка моста: `Stop-VideoBridge.ps1`. Перед просмотром видео в WPF остановите мост: прошивка может обслуживать только одного видеоклиента. WPF не запускает мост автоматически.

## Проверка исходников

Из корня проекта:

```powershell
dotnet build DroneControl.slnx -c Release -m:1
dotnet run --project tests/DroneControl.Tests -c Release -- --input-only
dotnet run --project tests/DroneControl.Tests -c Release
```

Первый набор тестов не использует сеть. Полный набор обменивается UDP только через `127.0.0.1`, без дрона. APK, декомпиляция, `bin`, `obj` и `dist` не являются редактируемыми исходниками приложения.
