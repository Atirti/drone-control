# Руководство пользователя

## Требования

- Windows и .NET 10 Desktop Runtime для WPF.
- Подключение компьютера к Wi-Fi `Du-HD4K-1072B853`.
- Дрон доступен по адресу `192.168.169.1`; в проверенной конфигурации компьютер получил `192.168.169.2/24`.

Интернет не нужен для работы с дроном. Установка .NET и восстановление NuGet-пакетов при сборке могут потребовать интернет.

## Просмотр в приложении

Откройте `dist/DroneControl/DroneControl.exe` и нажмите **Подключить**. Видео принимается автоматически. Состояние **Ожидание ответа дрона…** означает, что сокет открыт, но свежих ответов ещё нет; **Подключён** означает наличие принятого пакета за последние три секунды, а не проверку готовности к полёту.

Приложение отправляет видеоприветствие и подтверждения приёма. Полётные пакеты начинаются только после разрешения управления или нажатия остановки. **Отключить** завершает приём и очищает изображение. **Снимок** сохраняет текущий декодированный кадр в выбранный PNG-файл.

## Экранные стики

После ответа дрона включите разрешение управления. Используйте два экранных стика под видео.

| Элемент | Поведение |
|---|---|
| Левый стик вверх / вниз | Увеличение / уменьшение газа |
| Левый стик влево / вправо | Поворот влево / вправо |
| Правый стик вверх / вниз | Движение вперёд / назад |
| Правый стик влево / вправо | Движение влево / вправо |
| Скорость | Максимальная интенсивность: 10–100%, по умолчанию 30% |
| Взлёт / Посадка | Экранные кнопки, флаг команды на одну секунду |
| СТОП МОТОРОВ | Снимает разрешение управления и повторяет остановку с нулевым газом одну секунду |

Отклонение пропорциональное: половина хода даёт примерно половину выбранной интенсивности. Можно совмещать оси, в том числе двигаться по диагонали и одновременно поворачивать. Отклонение каждого стика ограничено кругом.

**Экранные стики:** удерживайте и перетаскивайте ручку мышью или пальцем. Мышью можно удерживать один стик за раз, двумя пальцами на multitouch-экране — оба одновременно. Отпускание или потеря захвата возвращает соответствующий стик в центр; второй стик продолжает работать. Клавиатурного управления нет.

Взлёт, посадка, разрешение управления и остановка выполняются экранными кнопками. После нажатия взлёта или посадки стики сбрасываются.

При потере фокуса окна разрешение управления снимается, оси сбрасываются в нейтраль. Автоматического возобновления нет: снова включите управление. При отсутствии ответов дрона три секунды действует тот же сброс. Уже запущенная аварийная остановка продолжает секундный импульс при потере фокуса.

Газ 128 — нейтраль исходного режима удержания высоты, а не команда выключения моторов. Само приложение не измеряет высоту, заряд и фактическую скорость. Реальное управление полётом пока не подтверждено. При обрыве сети команда остановки может не дойти.

## VLC и видеомост

Дрон передаёт собственный UDP-протокол, а не подтверждённый RTSP-поток. Видеомост собирает JPEG и выдаёт HTTP MJPEG без перекодирования:

```text
http://127.0.0.1:8088/video.mjpg
```

Варианты запуска из корня проекта:

```powershell
.\Start-VideoBridge.ps1
# Или открытая консоль; Ctrl+C завершает работу:
.\dist\DroneVideoBridge\DroneVideoBridge.exe
# Ограниченная проверка на 8 секунд:
.\dist\DroneVideoBridge\DroneVideoBridge.exe --seconds 8
```

Скрытый процесс останавливается через `Stop-VideoBridge.ps1`. Мост слушает только этот компьютер, максимум четыре HTTP-клиента. Он сохраняет первый кадр в `dist/DroneVideoBridge/first-frame.jpg`, перезаписывая его при следующем запуске. Этот файл может содержать изображение из вашей камеры.

WPF и мост не должны одновременно обращаться к дрону. Перед сменой программы завершите предыдущий видеоклиент, включая Android-приложение, если оно удерживает поток.

## Если что-то не работает

| Симптом | Проверка |
|---|---|
| Нет ответов | Проверьте Wi-Fi, IP в `ipconfig` и доступность `192.168.169.1` |
| Ping есть, видео нет | Закройте другие клиенты. Не привязывайте приём к порту 8800: видео приходит с 1234 |
| VLC не открывает ссылку | Убедитесь, что мост запущен на этом же компьютере и порт 8088 свободен |
| Ошибка Address already in use | Уже запущен мост или другая программа занимает 8088; не запускайте второй экземпляр |
| Требуется .NET | Для WPF нужен Desktop Runtime 10; обычного .NET Runtime недостаточно |
| Стики недоступны | Дождитесь ответа дрона и включите управление |
| Поток зависает | Проверьте сигнал Wi-Fi и исключите второго клиента; восстановление потерь BL реализовано частично |

Не отключайте брандмауэр целиком для диагностики. При необходимости разрешите конкретное приложение в используемой сети. Технический скрипт `tools/Probe-Video.ps1` описан в [документации разработчика](DEVELOPMENT.md).
