# Протокол Du-HD4K

[README](../readme.md) · [Архитектура](ARCHITECTURE.md) · [Геймпад](GAMEPAD.md)

Справочник по BL-протоколу, реализованному в клиенте. Форматы восстановлены из APK KY FPV и его нативных библиотек. Числа в примерах пакетов, маркеры и флаги записаны в шестнадцатеричном виде; размеры, смещения и диапазоны осей — в десятичном.

## UDP-транспорт

| Параметр | Значение |
| :--- | :--- |
| Адрес дрона | `192.168.169.1` |
| Порт запросов | UDP 8800 |
| Исходящий порт видео | UDP 1234 |
| Локальный порт клиента | Свободный порт, выделенный системой |
| Heartbeat | `EF 00 04 00` |
| Срок следующего heartbeat | 110 мс; отправка на ближайшем вызове таймера WPF |
| Период таймера WPF | 50 мс |
| Таймаут свежести ответа | 3 с |

Клиент использует UDP-сокет без `Connect`: порт видеопакетов отличается от порта запросов. Входящие пакеты фильтруются по IP дрона, маркеру BL и заявленной длине.

## Полётная команда

`Protocol.Flight` формирует пакет длиной 8 байт. Нейтраль всех осей — 128 (`80` hex).

| Смещение | Поле | Значение |
| :--- | :--- | :--- |
| 0 | Начало | `66` |
| 1 | Roll — крен | 1…255 |
| 2 | Pitch — тангаж | 1…255 |
| 3 | Throttle — газ | 0…255; входное значение 1 заменяется на 0 |
| 4 | Yaw — поворот | 1…255 |
| 5 | Флаги | Битовая маска команды |
| 6 | Контрольная сумма | XOR байтов 1…5 |
| 7 | Конец | `99` |

### Флаги

| Флаг | Назначение в APK | Поддержка в интерфейсе |
| :--- | :--- | :--- |
| `01` | Взлёт | Импульс 1 с |
| `02` | Посадка | Импульс 1 с |
| `04` | Остановка моторов | Импульс 1 с, газ 0 |
| `08` | Переворот | Нет |
| `10` | Безголовый режим | Нет |
| `20` | Unlock / fast return; точная семантика не установлена | Нет |
| `40` | Свет | Нет |
| `80` | Калибровка | Нет |

```text
Нейтраль  66 80 80 80 80 00 00 99
Взлёт     66 80 80 80 80 01 01 99
Посадка   66 80 80 80 80 02 02 99
Стоп      66 80 80 00 80 04 84 99
```

### Оси и скорость

`FlightInput` преобразует нормализованное отклонение стика в значение оси:

```text
value = 128 + trunc(range × axis)
```

`axis` находится в диапазоне −1…1. `trunc` отбрасывает дробную часть к нулю. Правый стик задаёт roll/pitch, левый — yaw/throttle; каждая пара ограничена единичным кругом.

| Режим | Диапазон roll/pitch | Крайние значения roll/pitch | Диапазон yaw/throttle |
| :--- | :--- | :--- | :--- |
| 30% | ±45 | 83…173 | ±127 |
| 60% | ±60 | 68…188 | ±127 |
| 100% | ±127 | 1…255 | ±127 |

Проценты обозначают режимы KY FPV и не являются линейным множителем для всех осей. Газ и поворот не зависят от режима. Мёртвая зона геймпада обрабатывается до формирования пакета.

## BL-оболочка

`Protocol.Wrap` добавляет к полётной команде 12-байтовый заголовок. Многобайтовые поля записываются в порядке **little endian**.

| Смещение | Размер, байт | Поле |
| :--- | :--- | :--- |
| 0 | 1 | Маркер `EF` |
| 1 | 1 | Тип `04` |
| 2 | 2 | Полная длина: 12 + длина команды |
| 4 | 4 | Номер последовательности; увеличивается для каждой команды |
| 8 | 2 | Длина команды |
| 10 | 2 | Ноль |
| 12 | N | Данные команды |

Нейтральная команда с номером последовательности 1:

```text
EF 04 14 00 01 00 00 00 08 00 00 00 66 80 80 80 80 00 00 99
```

При отключении после полётной отправки клиент также передаёт команду выхода `65` внутри BL-оболочки. Если полётных команд в сеансе не было, команда выхода не отправляется.

Входящие BL-пакеты начинаются с `93`; поле по смещению 2 содержит полную длину. Сообщение типа `03` длиной не менее 12 байт подтверждается ответом `EF 08 08 00`, за которым следуют исходные байты 4…7.

## Видеопакеты

Видеофрагмент имеет тип `01` в байте 1. Многобайтовые поля заголовка используют **little endian**.

| Смещение | Размер, байт | Поле |
| :--- | :--- | :--- |
| 8 | 8 | Идентификатор кадра |
| 32 | 4 | Индекс фрагмента, начиная с нуля |
| 36 | 4 | Количество фрагментов |
| 40 | 4 | Размер данных JPEG без восстанавливаемого заголовка |
| 44 | 2 | Ширина |
| 46 | 2 | Высота |
| 48 | 1 | Качество JPEG |
| 56 | До 1024 | Данные фрагмента |

Количество фрагментов повторяет формулу нативной библиотеки, включая дополнительный последний фрагмент при размере, кратном 1024:

```text
count = size / 1024 + 1           // целочисленное деление
lastFragmentSize = size % 1024
```

Сборщик допускает до 1025 фрагментов на кадр, размер данных до 1 МиБ и размеры изображения от 1 до 4096 пикселей по каждой оси. Метаданные фрагментов одного кадра должны совпадать. Перестановка и дублирование пакетов поддерживаются; неполные кадры не отображаются.

### Восстановление JPEG

Для уровней качества 5, 10, 25, 50, 75 и 100 используется соответствующий встроенный заголовок длиной 605 байт. По смещениям 145 и 147 записываются высота и ширина в порядке **big endian**. Затем добавляются данные кадра и маркер `FF D9`.

При качестве 0 и начале данных `FF D8` кадр передаётся как готовый JPEG. Неподдерживаемое качество не даёт изображения.

### Подтверждения фрагментов

`BlFrames.Acknowledgement` создаётся, когда индекс фрагмента кратен 16, получен последний фрагмент либо кадр собран полностью.

Ответ начинается с `EF 02`; по смещению 2 записана его полная длина. Пакет содержит одну запись кадра:

| Смещение | Поле |
| :--- | :--- |
| 32 | Идентификатор кадра |
| 40 | Состояние: 0 — неполный, 1 — полный |
| 44 | Длина записи |
| 48 | Битовая карта полученных фрагментов |

Битовая карта округляется до целого числа 32-битных слов. Последние 8 байт пакета остаются нулевыми. Сборщик хранит до четырёх незавершённых кадров; полный алгоритм повторных запросов и управления качеством оригинального клиента не воспроизведён.

## Источники формата

Локальные материалы разбора находятся в `analysis/`; этот каталог исключён из Git. Основные точки проверки диапазонов осей в `analysis/jadx/sources/com/cooingdv/kyfpv/`:

| Источник | Подтверждаемые значения |
| :--- | :--- |
| `adapter/TopListViewAdapter.java` | Соответствие `currPower` 4/9/14 режимам 30/60/100 |
| `fragment/DeviceBLFragment.java`, метод `getHalfLen` | Диапазоны правого стика 45/60/127 |
| `fragment/DeviceBLFragment.java`, метод `onMove` | Диапазон левого стика 127 и преобразование отклонений к целому числу |

Значения `getHalfLen` также сверены с `DeviceBLFragment.smali` в каталоге `analysis/apktool/smali/com/cooingdv/kyfpv/fragment/`. Формирование пакетов, диапазоны осей и обработка фрагментов проверяются в `tests/DroneControl.Tests`.
