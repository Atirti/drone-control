# drun-control

Приложение для Windows: видео с камеры Wi-Fi-дрона и управление с экранных стиков или геймпада. Построено на **C# · .NET 10 · WPF**, интерфейс — **Material Design**, поддержка контроллеров — **SDL3**.

Клиент предназначен для Du-HD4K с адресом `192.168.169.1` и протоколом BL, восстановленным из приложения KY FPV. Видеопоток принимается и отображается непосредственно в окне приложения.

## Возможности

- Просмотр видео с камеры через Wi-Fi.
- Два аналоговых экранных стика с поддержкой мыши и сенсорного ввода.
- Управление с геймпада, включая переключение скорости, взлёт, посадку и остановку моторов.
- Три режима скорости: **30 / 60 / 100%**.
- Сброс управления при потере фокуса, связи или отключении геймпада.

### Подключение к дрону

1. Подключите компьютер к сети дрона, например `Du-HD4K-1072B853`.
2. Откройте приложение и нажмите **Подключить**.
3. Дождитесь статуса **Подключён** и изображения с камеры.

Адрес дрона задан в приложении. Видео запускается после подключения; переключатель **Включить управление** отвечает только за полётные команды.

## Управление

Выберите **Экранные стики** или **Геймпад**, затем включите **Включить управление**. При использовании геймпада отпустите оба стика на 0,3 секунды, чтобы активировать ввод.

| Элемент | Действие |
| :--- | :--- |
| Левый стик ↑ / ↓ | Подъём / снижение |
| Левый стик ← / → | Поворот |
| Правый стик ↑ / ↓ | Движение вперёд / назад |
| Правый стик ← / → | Движение в стороны |
| LB | Скорость: 30 → 60 → 100 → 30% |
| Крестовина ↑ | Взлёт |
| Крестовина ↓ | Посадка |
| B | Остановка моторов |

Экранные стики перемещаются мышью или пальцами и возвращаются в центр при отпускании. Отклонение задаёт интенсивность команды; оси можно совмещать.

Скорость меняет чувствительность правого стика. Газ и поворот сохраняют полный диапазон во всех трёх режимах. Проценты обозначают режимы оригинального приложения, а не измеренную скорость полёта.

Кнопки геймпада работают при активном окне приложения. Взлёт и посадка требуют разрешённого управления; для **B** достаточно открытого соединения с дроном. Подробности подключения и поведения кнопок — в [руководстве по геймпаду](docs/GAMEPAD.md).
